# ohj1-slides — JYU Ohjelmointi 1 lecture slides

Multi-lecture Slidev monorepo. Each lecture lives in its own subfolder and
is hosted under a single domain at `/luento1/`, `/luento2/`, etc.

## Structure

```
ohj1-slides/
├── package.json          # single node_modules for all lectures
├── scripts/
│   └── build-all.mjs     # build one or all lectures
├── luento1/
│   └── slides.md
├── luento2/
│   └── slides.md
├── luento3/
│   └── slides.md
├── dist/                 # generated by build; served by nginx in container
│   ├── luento1/
│   ├── luento2/
│   └── luento3/
├── Dockerfile
├── docker-compose.yml
└── .github/
    └── workflows/
        └── deploy.yml
```

## Hosting

Everything is behind a single nginx reverse proxy at
`https://jyu-polls.dezhidki-hermes.party`:

| Path | Content |
|------|---------|
| `/luento1/` | Lecture 1 slides |
| `/luento2/` | Lecture 2 slides |
| `/vote.html` | Audience poll page |
| `/polls` (WS) | Poll WebSocket server |

## Docker deployment

```bash
docker compose up -d --build
```

The image contains:
- nginx serving static `dist/` + `vote.html`
- Node.js poll server on port 3032 (internal)
- supervisord managing both processes

## Local dev

```bash
npm install
npm run dev:1   # serve luento1 on :3041
```

## Adding a new lecture

1. Create `luento4/slides.md`
2. Add `"dev:4"` script to `package.json`
3. Push — CI builds and deploys automatically

## Environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PRESENTER_TOKEN` | `changeme` | Poll presenter password (= `--remote` value) |
| `POLL_SERVER_PORT` | `3032` | Internal WS port |
